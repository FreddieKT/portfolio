An AI tool that works with notes does not need to start with every file on a computer. A selected source set is a clearer place to begin.

## Start with a small, deliberate set

Choose notes that fit the question being explored. Keep track of which sources contributed to an answer so the result can be checked against the originals.

A related fragment is a lead, not proof that the tool understood the whole situation.

## Local files do not settle the privacy question

Where notes are stored and where a model processes them are separate questions. Before using personal material, check what the tool sends, which service receives it, and what output is saved.

## Use different material for a public demo

A demo can use fictional or sanitized notes to show the same behavior. The original private material does not need to become part of the public example.

Generated briefs should remain drafts until they have been reviewed. Finding a connection and deciding to share it are different steps.
